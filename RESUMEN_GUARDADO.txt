═══════════════════════════════════════════════════════════════════════════
   PRÓXIMOS PASOS CRÍTICOS
═══════════════════════════════════════════════════════════════════════════

1️⃣ ESPERAR A QUE EL PUSH TERMINE
   ⏳ Estado actual: 64% - Quedan ~300 MB por subir

2️⃣ CREAR ZIP VÁLIDO (NO USAR WINDOWS)
   
   ⚠️ IMPORTANTE: PrestaShop rechaza ZIPs de Windows
   
   Instalar 7-Zip:
      winget install 7zip.7zip
   
   Crear ZIP:
      cd "H:\Migration-Prestashop"
      & "C:\Program Files\7-Zip\7z.exe" a -tzip ps9csvexport.zip .\ps9csvexport\*
   
   O manualmente:
      - Clic derecho en carpeta ps9csvexport
      - 7-Zip → Añadir a archivo...
      - Formato: ZIP
      - Nombre: ps9csvexport.zip

3️⃣ SUBIR A PRESTASHOP 9
   - Acceder a tumanitasia.es/admin
   - Módulos → Module Manager
   - Subir un módulo → ps9csvexport.zip
   - Instalar y Configurar

4️⃣ EXPORTAR DESDE PS 1.7.6
   Orden de exportación (todos desde PS 1.7.6):
   1. Categorías
   2. Marcas
   3. Proveedores
   4. Productos
   5. Clientes
   6. Direcciones

5️⃣ IMPORTAR EN PS 9
   ⚠️ ORDEN CRÍTICO - RESPETAR ESTE ORDEN:
   1. Categorías (SIN truncar tabla)
   2. Marcas (puede truncar)
   3. Proveedores (puede truncar)
   4. Productos (NO truncar - puede tardar 10 min)
   5. Clientes (opcional)
   6. Direcciones (después de clientes)
